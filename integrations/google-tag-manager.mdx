Once configured, you can capture widget activity in your analytics or use these interactions to trigger custom events.

## Events You Can Track

The Captivated Website Widget can track events including:

- Widget window opened
- Widget window closed
- Visitor initiated a Live Chat conversation
- Visitor sent a Live Chat message
- Visitor sent a text message
- Visitor ended a Live Chat

## How It Works

[Google Tag Manager](https://tagmanager.google.com/) allows you to manage analytics and tracking tags on your website without manually adding separate code for each event.

Captivated's GTM template is designed specifically for the Captivated Website Widget and allows you to capture supported widget events without writing custom code.

You can use this data to better understand how visitors interact with your widget or trigger additional events within your analytics setup.

## Install the Captivated GTM Template

For complete installation and configuration instructions, follow the official [Captivated Google Tag Manager installation guide](https://github.com/CaptivatedLLC/official-gtm-tag).

The guide walks through adding the Captivated Widget template to your Google Tag Manager container and configuring the available events.

<Note>
  If you need the installation script for your Captivated Website Widget, you can also find it under the widget's **Installation** tab in Captivated. See our Website Widgets guide for additional instructions.
</Note>
