---
title: "Service Assistant (SA5) Integration"
description: "Integrating Service Assistant (SA5) with Captivated allows your team to send text messages to customers directly from SA5 using Captivated."
---

With the integration, you can:

- Send bulk messages from supported SA5 reports using **Send to Texting**
- Create SA5 texting templates using customer data fields
- Track unsuccessful messages through the SA5 Call Log
- Manage customer texting preferences and opt-outs
- Use the Captivated Chrome extension to send individual messages and view conversation history from a customer's SA5 record

## Step 1: Connect Captivated to SA5

You'll need the **API key** provided in your Launch Plan. 

### Add Your Captivated API Key

1. Copy your Captivated API key.
2. In SA5, select the **gear icon**.
3. Select **Integrations Setup**.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-2.58.31-PM.png)

Expand **Texting Provider**.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-2.59.53-PM.png)

<Note>
  Access to Integrations must be enabled within **Employee Security** to make changes. Settings can be configured for an individual branch or copied to other branches the User has access to using **Copy to All Branches**
</Note>

5. Paste your Captivated API key into the **API Key** field.
6. Enter the Captivated number customers should receive messages from in the **SMS Number** field.

> **Important:** Enter the 10-digit SMS number using **numbers only**. Do not include spaces, periods, dashes, or parentheses.
>
> Example: `1112223333`

### Configure Call Logs for Unsuccessful Messages

You'll also configure how SA5 handles messages that are unsuccessful.

**Opt-Out Call Status:**<br />Choose the Call Log status that should be used when a message is unsuccessful.

**Call Log Assigned Employee:**<br />Choose the employee who should receive Call Log entries for unsuccessful messages.

Common reasons a message may be unsuccessful include:

- The customer has opted out
- An invalid or incorrect phone number
- The selected template isn't assigned to the customer's branch
- An API key isn't available

This makes it easier to identify customers who didn't receive the intended message and determine why.

## Step 2: Create Texting Templates in SA5

Before using **Send to Texting** from an SA5 report, you'll need to create your texting templates within SA5.

<Note>
  Texting templates created in SA5 are completely separate from Templates created within Captivated
</Note>

### Create a Texting Template

1. Select the **gear icon**.
2. Select **Document Template Setup**.

2A: Click on the gear icon and then Document Template Setup.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.04.46-PM.png)

<Note>
  You can check or uncheck **Show System Templates** to control which existing templates are displayed.
</Note>

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.05.17-PM.png)

- Select the **\+** icon to create a new template.
- Enter a name for your template.
- Under **Template Type**, select **Texting**.
- Compose your message.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.08.03-PM.png)

### Add Data Fields

SA5 data fields allow you to personalize the message using information from the customer's record.

1. Select the **three-bullet list**.
2. Find the data field you want to use.
3. Drag and drop it into the **Letter Text** field.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.12.54-PM.png)

<Warning>
  **Keep message length in mind:** Longer SMS messages may be divided into multiple segments. Data fields can also cause the final character count to vary from customer to customer.
</Warning>

#### Step 3: Send Bulk Messages From SA5

The **Send to Texting** option allows you to send messages from supported SA5 reports through Captivated.

Depending on your SA5 setup, this may be available from reports such as:

- Unpaid Invoices
- Unserviced List
- Credit Hold
- Route Loose Work
- Customer List
- Invoice Printing
- Aging Report
- Additional reports that include **Send to Texting** under Actions

<Danger>
  Once a bulk message has been sent, it **cannot be unsent**. Carefully review the customers included in your report and your message template before sending.
</Danger>

### How Phone Numbers Are Selected

Messages are only sent to customers who have a text or cell phone number on their customer record.

If the customer has both, only one message is sent, with the **text number taking priority**.

### Send a Message From a Report

1. Select the **Reports** icon.
2. Open the appropriate report.
3. Configure and run the report as you normally would.

![](https://learn.captivated.works/wp-content/uploads/2020/04/Screen-Shot-2022-03-17-at-10.21.31-AM-1024x494.png)

- Select the **Actions** button.
- Under **Targets**, select **Send to Texting**.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.22.38-PM.png)

6. Select the texting template you want to use.
7. Review your send options.
8. Review the **Captivated Conversation Options**.
9. Send your messages.

<Warning>
  **Recommended:** Leave both **Captivated Conversation Options unchecked** for the best experience. If these options are selected, messages may appear in Captivated as new queued conversations
</Warning>

![](https://learn.captivated.works/wp-content/uploads/2020/04/Screen-Shot-2021-08-23-at-3.57.01-PM-565x1024.png)

**Be Careful With the Send to Texting Shortcut**

<Danger>
  Selecting **Send to Texting** next to the **Preview** button at the bottom of the report automatically sends the most recently used template.

  Always confirm your report and intended recipients before using this option.
</Danger>

## Sending Text Aheads From Invoice Printing

One common use of the integration is sending Text Aheads from **Invoice Printing**.

1. Add the appropriate customers to your search.
2. Select **Go to Map** to route them, or select **Next** to view the list.
3. Before generating or printing invoices, select **Actions** from the left-hand menu.
4. Under **Targets**, select **Send to Texting**.
5. Select your template.
6. Review your send options and Captivated Conversation Options.
7. Send your messages.

<Warning>
  SA5 allows you to select a future send time. This is not recommended for this workflow because each message may appear as a new queued conversation in Captivated at the selected date and time.
</Warning>

## What Happens After Sending?

After sending, SA5 displays a pop-up showing the number of:

- **Successful sends**
- **Unsuccessful sends**

If any messages were unsuccessful, check the **Call Log** to see which customers didn't receive the message and why.

Common reasons include:

- Customer opted out
- Invalid phone number
- Template isn't assigned to the customer's branch
- API key isn't available

<Note>
  An unsuccessful message means the message did **not** come into Captivated.
</Note>

### Review Sent Messages in Captivated

To find and review these conversations in Captivated, change your conversation filters from:

**Mine → Everyone**

and

**Active → All**

# Managing Customer Opt-Outs

It's important to account for customers who should not receive text messages when building your SA5 reports.

## Exclude Customers Who Have Opted Out

When configuring your report:

1. Select the **\+** next to **Advanced Options**.
2. Expand **Preferences**.
3. Choose **Allowed**.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.19.01-PM.png)

- If a customer replies **STOP**, the **Don't Text** checkbox is automatically selected on their SA5 customer record under:
  **Contact → Preferences**
  This prevents messages from being sent to that customer through an SA5 report.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-04-29-at-3.21.22-PM.png)

**SA5 Don't Text vs. Captivated Opt-Outs**

<Note>
  The **Don't Text** preference within SA5 and an opt-out within Captivated do not work exactly the same way
</Note>

If an SA5 User manually selects **Don't Text** from the Customer Details page, that preference is **not honored by the Captivated Chrome extension**.

If the customer should also be prevented from receiving messages sent directly through Captivated:

1. Open the customer in Captivated.
2. Select the **information icon**.
3. Choose **Opt Out**.

If a customer is opted out in Captivated, they cannot be messaged on that Channel until they send a new inbound message.

![](https://learn.captivated.works/wp-content/uploads/2021/04/Screen-Shot-2021-05-03-at-11.18.14-AM.png)

# AMA Before Service Texts

Texting through the Captivated integration is **independent of AMA Before Service Texts**.

Within SA5:

- The SMS Number on the Company Setup parameter page is labeled **AMA SMS Number**.
- AMA texting preferences operate separately from Captivated's texting integration.
- The **Don't Text** contact preference used for Captivated does not impact AMA.

Keeping these separate is important when troubleshooting why a customer did or did not receive a particular type of text.

# Step 4: Send Individual Messages Using the Captivated Chrome Extension

In addition to bulk messaging from SA5 reports, you can use the Captivated Chrome extension to send an individual customer a message and access their Captivated conversation history without leaving their Customer Details page.

First, [install the Captivated Chrome extension](https://captivatedllc.mintlify.site/integrations/googlechromeextension).

### Send an Individual Message

1. Sign in to your Captivated account.
2. Open the customer's **Customer Details** page in SA5.
3. Open the **Captivated Chrome extension**.
4. Select the green **New Message** button next to the customer's name.

![](https://learn.captivated.works/wp-content/uploads/2020/04/Chrome-Extenstion-Step-1-1024x650.png)

Choose the Captivated Channel you want to send the message from.

![](https://learn.captivated.works/wp-content/uploads/2020/04/Chrome-Extension-Select-Line-1024x561.png)

6. Compose your message.
7. Select **Send**.

![](https://learn.captivated.works/wp-content/uploads/2020/04/Chrome-Extension-Message-Send-1024x564.png)

The Captivated Chrome extension checks the phone numbers associated with the customer's SA5 account and matches them with previously texted numbers when available.

If the customer has opted out within Captivated, they cannot be messaged again on that Channel until they send your business a new inbound message.

### View Conversation History

Select the **contact card** next to the text bubbles within the extension to view the customer's previous Captivated conversation history.

## Troubleshooting

<Accordion title="Why didn't my message send?">
  Check the SA5 **Call Log**. Common reasons for an unsuccessful message include:

  - The customer has opted out
  - The customer's phone number is invalid
  - The template isn't assigned to the customer's branch
  - An API key isn't available
</Accordion>

<Accordion title="Why don't I see Integrations Setup?">
  Integration access must be enabled within **Employee Security**.
</Accordion>

<Accordion title="Why can't I find my SA5 template in Captivated?">
  SA5 texting templates and Captivated Templates are separate. Templates created within SA5 are used with the SA5 **Send to Texting** functionality.
</Accordion>

<Accordion title="Where can I find messages sent from SA5 in Captivated?">
  Change your Captivated conversation filters to **Everyone** and **All** to locate conversations beyond those currently assigned to you.
</Accordion>

<Accordion title="Why are messages appearing as new queued conversations?">
  Review the **Captivated Conversation Options** when sending from SA5. For the recommended experience, leave both options unchecked.
</Accordion>

<Accordion title="I selected Don't Text in SA5. Why can the customer still be texted from the Chrome extension?">
  The SA5 **Don't Text** preference does not prevent a User from messaging the customer through the Captivated Chrome extension. The customer must also be opted out within Captivated.
</Accordion>

<Accordion title="Can I unsend a bulk message?">
  No. Once a bulk message has been sent, it cannot be unsent. Always review your recipients, template, and send options before sending.
</Accordion>
