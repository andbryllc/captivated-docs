<Warning>
  Announcements should not be used for sales or marketing messages unless your business has the appropriate consent from recipients to receive those messages.
</Warning>

## FAQ's

<Accordion title="How many recipients can I send an announcement to?">
  There is not a set recipient limit; however, messages are throttled by SMS carriers. Larger announcements can take additional time to send, so always review the **Estimated Recipients** and estimated sending time before sending.
</Accordion>

<Accordion title="How many texts are used from my plan when I send an announcement?">
  Usage is based on **message segments × number of recipients**. A standard SMS segment is generally 160 characters, but longer messages and certain characters can result in multiple segments.

  Before sending, review the estimated segment count and number of recipients displayed in Captivated. Keeping announcements short helps reduce usage and improve readability.
</Accordion>

<Accordion title="Can I unsend an announcement?">
</Accordion>

Before selecting **Send**, carefully review your selected contacts and tags, excluded tags, estimated recipients, message content, and segment count.

If an announcement is scheduled for a future date and has not started sending, the scheduled messages can be canceled before they send. Learn more about [scheduled messages](https://captivatedllc.mintlify.site/features/scheduling-a-message).

<Accordion title="Do recipients see the other recipients or their replies?">
  No. Announcements are sent BCC, so recipients do not see who else received the message. Replies return to Captivated as individual conversations.
</Accordion>

<Accordion title="Can I use tags to choose who receives an announcement?">
  Yes. You can use tags to **include or exclude contacts** from your announcement audience. When using multiple tags, you can also use **Match Any** or **Match All** to further define your recipients.

  Because tags can significantly change who receives your message, carefully review the recipient counts before sending. See the [Announcements guide](https://captivatedllc.mintlify.site/features/announcements) for full instructions.
</Accordion>

<Accordion title="Why can't I send another message from an existing announcement?">
  Additional announcement messages cannot be sent from an existing announcement. If you need to message the group again, create a new announcement. Using tags can make it easier to quickly select the same audience in the future.
</Accordion>

<Accordion title="Can I send a group text where recipients see each other's replies?">
  Captivated's customer-facing Announcements are BCC messages, so recipients cannot see each other's responses. If you'd like to send a group text, you can do that. Learn how [here](https://app.mintlify.com/captivatedllc/captivatedllc/~/c3228b7d-f547-40a0-961f-f9aebab7fb14).
</Accordion>
