## What Are Keyword Actions?

**Keyword Actions** allow Captivated to automatically take action when an incoming message matches rules you define.

Think of it as:

**When a contact sends a message that matches these rules → Captivated automatically performs these actions.**

Keyword Actions can:

- Send an automated reply or Message Template.
- Add one or more Tags to the contact.
- Remove one or more Tags from the contact.
- Perform multiple actions at the same time.

## Create a Keyword Action

To create a Keyword Action:

1. Open **Administration**.
2. Select **Keyword Actions**.
3. Create a new Keyword Action.
4. Add the rule or rules that should trigger the action.
5. Choose whether the message must match **Any** or **All** of your rules.
6. Select the action or actions Captivated should perform.
7. Save your changes.
8. Open the **Channels** tab and select the Channels where the Keyword Action should be active.

<Warning>
  A Keyword Action won't trigger unless it has been applied to the appropriate Channel.
</Warning>

## Set Your Rules

Rules determine which incoming messages trigger your Keyword Action.

You can create a single rule or combine multiple rules.

When using multiple rules, choose:

| Match Type | How It Works |
| :-- | :-- |
| **Any** | The Keyword Action triggers when the incoming message matches at least one of your rules. |
| **All** | The Keyword Action only triggers when the incoming message matches all of your rules. |

## Choose What Happens Next

Once the rules are met, Captivated can automatically perform one or more actions.

### Send an Auto-Reply

Send a custom message or an existing Message Template automatically.

This is useful for providing information customers frequently request without requiring someone on your team to respond manually.

### Add Tags

Automatically add one or more Tags to the contact's record.

Tags can help you organize contacts and create targeted groups for future communication.In the Administration section of Captivated, Administrators can set up Keyword Actions that trigger an auto-reply. With our latest update, you can now add or remove tags when a keyword is sent to your number in Captivated.

### Remove Tags

Automatically remove one or more Tags from the contact's record.

This is especially helpful when customers use keywords to manage their communication preferences.

## Ways to Use Keyword Actions

Keyword Actions can automate a variety of common customer interactions.

### Answer Frequently Asked Questions

Create keywords that automatically provide commonly requested information.

**Example:**

Customer texts:

> HOURS

Captivated responds with your current business hours.

### Share Helpful Resources

Use keywords to automatically send customers:

- Website links
- Forms
- Payment links
- Review requests
- Scheduling information
- Other frequently requested resources

### Manage Contact Lists with Tags

Keyword Actions can automatically add or remove Tags based on a customer's response.

For example, a school could allow parents to text:

> WEATHER

to be added to a Tag used for school closing and delay announcements.

### Manage Communication Preferences

Keyword Actions can also help customers indicate which types of communications they'd like to receive.

For example:

> Text **SPECIALS** to receive information about upcoming specials.

Captivated can automatically add the appropriate Tag to that contact for future communications.

<Note>
  Tags are a helpful way to organize contacts, but adding a Tag does not replace any consent requirements that may apply to marketing or promotional text messages.
</Note>

## Apply Keyword Actions to Channels

After creating your Keyword Action, choose which Channels should use it.

1. Open the Keyword Action.
2. Select the **Channels** tab.
3. Choose the appropriate Channel or Channels.
4. Save your changes.

This allows the same Keyword Action to be used across multiple texting numbers when appropriate.

## Best Practices

When creating Keyword Actions:

- Choose keywords that are simple and easy for customers to remember.
- Keep automated responses short and conversational.
- Test the Keyword Action before promoting it to customers.
- Make sure it's applied to the correct Channels.
- Review your Keyword Actions periodically to ensure the information being sent is still current.
- Be careful when using Keyword Actions for promotional subscriptions or communication preferences to ensure your opt-in process meets applicable requirements
