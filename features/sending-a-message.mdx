## Start a New Message

1. Select the green **New Message**.
2. Search for the contact by **name or phone number**.

### If the Contact Already Exists

If the contact already exists in Captivated, select their name from the search results to continue.

### If the Contact Doesn't Exist

If you don't find the contact, select **\+ Add a New Contact**.

Enter the contact's information, including their **First Name** and **Last Name**, then select **Save Contact and Continue**.

<Tip>
  Search for the contact before creating a new one to help prevent duplicate contact records.
</Tip>

## Salutation

When creating a contact, you can optionally enter a preferred name or greeting in the **Salutation** field.

Captivated uses the `{{salutation}}` merge field to personalize [Templates](/features/templates).

For example, a template that begins:

`Hi {{salutation}},`

will use the value saved in the contact's **Salutation** field. If no Salutation has been entered, Captivated will use the contact's **First Name** instead.

## Select a Channel

If you have access to multiple [SMS Channels](/administration/admin-channels), you may be prompted to choose which channel you'd like to send the message from.

![Select an SMS channel](https://learn.captivated.works/wp-content/uploads/2018/01/Screenshot-2023-08-29-at-3.47.03-PM.png)

Select the appropriate channel to continue.

## Compose and Send Your Message

Once you've selected an existing contact or created a new one, enter your message in the **Write a Message** field.

Review your message and select the green **Send** button when you're ready.

![Draft and send your message](https://learn.captivated.works/wp-content/uploads/2018/01/Screenshot-2023-08-29-at-3.50.18-PM.png)
