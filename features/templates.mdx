Message Templates help your team save time and provide consistent responses without typing the same message over and over.

Templates can include:

- Text
- Merge Fields
- Fill-in-the-blank fields
- Attachments
- Captivated features such as Forms, payment requests, booking requests, and more

## Create a Template

There are two ways to create a new Template:

1. Create one from the **Templates** section.
2. Save a message as a Template while you're writing it.

### Create a Template from the Templates Section

1. Open **Conversations \> Templates**.
2. Select the option to add a new Template.
3. Give your Template a descriptive name.
4. Enter your message.
5. Add Merge Fields, fill-in-the-blank fields, or attachments as needed.
6. Save your Template.

<Tip>
  Give Templates simple, recognizable names. Users can search for Templates by name when composing a message, so names such as **Appointment Reminder**, **Payment Follow-Up**, or **Service Complete** are easier to find than generic names.
</Tip>

## Personalize and Manage Templates with Fields

Captivated offers several types of fields that make Templates easier to personalize and maintain.

Depending on what you're trying to accomplish, you can use **Merge Fields, Data Fields, or Fill-in-the-Blank Fields**.

### Merge Fields

**Merge Fields** automatically insert information that is specific to the contact, User, or another connected data source.

For example:

> Hi \{\{salutation\}\}, we're looking forward to seeing you!

When the Template is used, `{{salutation}}` is automatically replaced with the appropriate information for that contact.

Depending on your Captivated setup, Merge Fields may include contact information, User information, [Custom Fields](/features/custom-fields), or information from integrated systems.

### Data Fields

**Data Fields** store one shared value that can be used across multiple Templates.

Unlike a Merge Field, the value does **not change based on the contact**. The same value is inserted anywhere that Data Field is used.

For example, if your business uses the same scheduling link in several Templates, you could create a Data Field:

> \{\{scheduling\_link\}\}

Set the value of that Data Field to your current scheduling URL, then use `{{scheduling_link}}` anywhere you need it.

If your scheduling link changes later, simply **update the Data Field once**. Every Template using that Data Field will automatically use the new value—there's no need to find and edit each Template individually.

Data Fields are especially useful for information such as:

- Business hours
- Scheduling links
- Payment links
- Website URLs
- Office addresses
- Support phone numbers
- Pricing or standard fees
- Promotional codes

<Tip>
  If the same piece of information appears in multiple Templates and may change in the future, use a Data Field instead of typing the value directly into every Template.
</Tip>

### Fill-in-the-Blank Fields

**Fill-in-the-Blank Fields** are used when information needs to be entered manually each time a Template is sent.

To create one, place your desired field name inside double curly brackets.

For example:

> Your technician should arrive between \{\{arrival\_time\}\}.

When a user selects the Template, Captivated will prompt them to enter the arrival time before sending the message.

## Which Field Should I Use?

Here's an example that uses all three:

> Hi \{\{salutation\}\}, your appointment is scheduled for \{\{appointment\_time\}\}. If you need to make a change, visit \{\{scheduling\_link\}\}.

In this Template:

| Field | Type | Why |
| :-- | :-- | :-- |
| `{{salutation}}` | **Merge Field** | Automatically changes based on the contact receiving the message. |
| `{{appointment_time}}` | **Fill-in-the-Blank Field** | The sender enters the appropriate appointment time before sending. |
| `{{scheduling_link}}` | **Data Field** | Uses the same scheduling link across Templates and can be updated in one place. |

A simple way to remember the difference:

**Merge Field = unique to the contact**<br />**Data Field = one value shared across Templates**<br />**Fill-in-the-Blank = entered each time you send**

<Tip>
  Always review your Template before sending to make sure Merge Fields populated correctly, Data Fields contain current information, and Fill-in-the-Blank Fields have been completed.
</Tip>

## Add Attachments to a Template

You can include attachments with Templates when your team regularly sends the same file or media.

Supported attachments may include common file types such as images, PDFs, and documents.

When the Template is selected, the attachment will be included with the message.

<Tip>
  Periodically review Templates containing attachments to make sure the file is still accurate and current.
</Tip>

## Add Captivated Features to a Template

Templates can also include certain Captivated actions and requests, allowing your team to quickly send frequently used workflows.

Depending on the features available to your account, you may be able to add:

- [Contact Exchange Requests](/features/contact-exchange-request)
- [Payment Requests](/features/express-pay)
- [Google Review Requests](/premium-features/google-review-requests)
- [Booking Requests](/integrations/scheduling)
- [Location Requests](/premium-features/requesting-a-location)
- [Forms](/premium-features/requesting-a-form)

This is especially useful when your team regularly sends the same request with similar accompanying language.

## Create a Template While Writing a Message

If you find yourself repeatedly typing the same response, you can save it as a Template without leaving the conversation.

1. Draft your message.
2. Open the **three-dot menu**.
3. Select **Save as Template**.
4. Give the Template a recognizable name.
5. Save it.

The message will then be available for future conversations.

## Share a Template

When you create a Template, it is automatically available to you.

You can also share it with individual Users or entire Teams.

1. Open the Template.
2. Select **Share**.
3. Choose the Users or Teams who should have access.
4. Decide whether they should also have **Write Access**.
5. Save your changes.

<Tip>
  Limit Write Access to users who should be responsible for maintaining shared Templates. This helps prevent accidental changes to messages used across your organization.
</Tip>

## Send a Template

From an open conversation, you can find and use an available Template from the message field.

You can either:

- Open the Template selector and choose a Template.
- Begin typing the Template's name to search for it.

Once you've selected a Template:

1. Complete any fill-in-the-blank fields.
2. Review populated Merge Fields.
3. Review the entire message.
4. Make any necessary adjustments.
5. Send when ready.

<Warning>
  Always review a Template before sending it. Pay particular attention to names, Merge Fields, dates, links, attachments, and manually entered information.
</Warning>

## View and Edit Templates

Open **Conversations \> Templates** to manage your Template library.

From here, you can search and filter Templates to find the one you need.

Select a Template to review its content, sharing permissions, or other available settings.

Keeping your Template library organized makes it easier for users to find the correct response and reduces the chance of outdated Templates being used.

## Archive a Template

If a Template is no longer being used, archive it rather than leaving it in your active Template library.

Archiving removes the Template from your active list without permanently deleting it.

To archive a Template:

1. Open **Conversations \> Templates**.
2. Locate the Template you no longer need.
3. Select the Template.
4. Choose **Archive**.

Archived Templates can be viewed using the **Archived** filter.

## Restore an Archived Template

If you need to use an archived Template again:

1. Filter your Template list to **Archived**.
2. Select the Template.
3. Choose **Restore**.
4. Review the Template content and sharing permissions before using it again.

<Tip>
  **Best Practice:** If a Template has been archived for some time, review its wording, links, attachments, Merge Fields, and compliance language before restoring it.
</Tip>

## Safe Templates & Compliance Settings

Some Captivated accounts use compliance settings that allow Administrators to designate certain Templates for specific messaging workflows.

If available on your account, Administrators may see a **Safe to Send** setting when creating or editing a Template.

This setting works with your organization's Captivated compliance configuration and should only be enabled for Templates that meet the requirements established for that messaging workflow.

<Info>
  A Template setting does not replace applicable consent or messaging requirements. Your organization is responsible for ensuring messages are appropriate for the recipient and the intended use.
</Info>

If you're unsure whether a Template should be designated as safe, contact Captivated Support before changing the setting.

## Template Best Practices

- Give Templates clear, searchable names.
- Keep messages concise and conversational.
- Use Merge Fields to personalize messages when appropriate.
- Use fill-in-the-blank fields for information that changes with each send.
- Review messages before sending, even when using a Template.
- Limit Write Access for important organization-wide Templates.
- Archive Templates your team no longer uses.
- Periodically review shared Templates for outdated information, links, attachments, or language.
- Be especially careful when using Templates for large [Announcements](/features/announcements).
