## Print or Download a Transcript

1. Open the conversation you want to save.
2. Select the **three-dot menu** below the message field.
3. Choose **Print Transcript**.
4. Select whether you'd like to:
   - **Print** the conversation, or
   - **Save/Download as PDF** using your browser's print options.

The transcript will include the conversation history available in that thread.
