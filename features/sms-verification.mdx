Not sure whether a contact's phone number can receive texts? Captivated's **SMS Verification badge** provides information about the number and its ability to receive SMS messages.

You'll see a colored badge next to the contact's phone number. Hover over the badge for additional information about the number.

## What Do the SMS Verification Colors Mean?

| Badge | Status | What It Means |
| :-- | :-- | :-- |
| 🟢 **Green** | SMS Verified | The number is textable and has successfully communicated via SMS in Captivated. |
| 🔵 **Blue** | Mobile Verified | The number has been identified as a mobile number and is expected to support SMS. |
| 🟡 **Yellow** | Non-Mobile / VoIP | The number is not identified as a traditional mobile number. SMS capability may vary depending on the number and provider. |
| 🔴 **Red** | Confirmed Landline | The number has been identified as a landline and cannot receive SMS messages. |
| ⚪ **Gray** | Unknown | Captivated has not yet been able to verify the number type or SMS capability. |

<Tip>
  Hover over the verification badge whenever you need additional information about a contact's number.
</Tip>

## Where Can I Find the Verification Badge?

The SMS Verification badge is available in several places throughout Captivated, including:

- The **Contacts** list
- An individual **Contact record**
- When adding a new contact while starting a conversation

## What If a Number Shows as Textable but My Message Fails?

A textable number doesn't guarantee that every message will be successfully delivered. Messages can still fail for reasons such as carrier filtering, network issues, the recipient's service status, or messaging restrictions.

If a message fails, use Captivated's [Failed Message Indicator](/features/sms-error-report) to view additional information about the failure.

## Need Help?

If you're unsure whether a number can receive texts or believe a verification status is incorrect, contact **Captivated Support** using the in-app **Support** option.
