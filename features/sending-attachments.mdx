## Send an Attachment

1. Open the conversation with the contact.
2. Select the **paperclip icon** below the message field.
3. Choose the file you'd like to attach.
4. Add a message along with the attachment, if desired.
5. Select **Send**.

![](https://learn.captivated.works/wp-content/uploads/2018/01/Screen-Shot-2018-12-01-at-5.13.54-PM-1024x734.png)

Before sending, you can remove an attachment by selecting the **X** next to the file.

## Image, Video and Audio File Sizes

Images, videos, and audio are sent as **MMS**, and mobile carriers have limits on the size of files they will accept.

<Warning>
  Large media files may fail to deliver. If you're having trouble sending an image, video, or audio file, try reducing the file size and sending it again.
</Warning>

![](https://learn.captivated.works/wp-content/uploads/2018/01/Screenshot-2025-08-19-at-11.05.51%20AM.png)

## MMS File Size Limits by Carrier

Because file-size limits can vary by carrier, we recommend keeping MMS attachments as small as possible to help ensure successful delivery.

![](https://learn.captivated.works/wp-content/uploads/2018/01/Screenshot-2025-08-19-at-11.10.12%20AM.png)

![MMS File Size Per Carrier 2026](/images/MMS-File-Size-Per-Carrier-2026.png "MMS File Size Per Carrier 2026")

<Tip>
  Compress large images or videos before attaching them to Captivated. Reducing the file size can improve deliverability without requiring you to remove the attachment altogether.
</Tip>

## Documents and Other Files

Files such as PDFs, Word documents, and Excel files can also be attached using the **paperclip icon**.

Depending on the file type, the recipient may receive a link that allows them to open or download the attachment.

## Having Trouble Sending an Attachment?

If an attachment fails to send:

1. Check the attachment's file size.
2. Reduce the size if you're sending an image, video, or audio file.
3. Try sending the attachment again.
4. If it continues to fail, contact Captivated Support for assistance.
