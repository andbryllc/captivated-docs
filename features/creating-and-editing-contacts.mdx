There are two primary ways to create a contact in Captivated:

- From the **New Message** button when you're ready to start a conversation
- From **Contacts** when you simply want to add a contact to your contact list

## Create a Contact from New Message

This is the quickest option when you want to **add a new contact and immediately send them a message**.

1. Select the green **New Message** button.
2. Enter the contact's phone number.
3. If the phone number isn't already associated with a contact, select the option to **add a new contact**.
4. Enter the available contact information.
5. Select **Save Contact and Continue**.

Once the contact is saved, the conversation will open so you can compose your message.

<Tip>
  Before creating a new contact, check whether the phone number already exists in Captivated to help prevent duplicate contact records.
</Tip>

## Create a Contact from Contacts

If you want to add someone to Captivated without immediately sending them a message, create the contact from the **Contacts** section.

1. Select **Contacts** from the navigation menu.
2. Select **\+ Add**.
3. Enter the contact information you have available.
4. Add any applicable Tags or other information.
5. Select **Save**.

Once saved, you can continue editing the contact or start a conversation with them.

Learn more about [Tagging Contacts](/features/tagging-contacts).

## Edit a Contact

There are two ways to edit an existing contact:

- From the contact details within a conversation
- From the **Contacts** section

### Edit from a Conversation

If you're already communicating with the contact:

1. Open the conversation.
2. Open the contact's **information/details** panel.
3. Select **Edit**.
4. Update the appropriate information.
5. Select **Save**.

<Note>
  A contact's phone number cannot be changed using this method. To edit a phone number, use the **Contacts** section.
</Note>

### Edit from Contacts

For access to the full contact record:

1. Select **Contacts** from the navigation menu.
2. Search or filter to locate the contact.
3. Select the contact's name.
4. Select **Edit**.
5. Make your changes.
6. Select **Save**.

Use this method when you need to change a contact's **phone number**.

<Check>
  Double-check a phone number before changing it to make sure you're updating the correct contact record.
</Check>

## Quick Reference

| I Want To... | Where to Go |
| :-- | :-- |
| Create a contact and immediately text them | **New Message** |
| Create a contact without sending a message | **Contacts → \+ Add** |
| Edit basic contact information while in a conversation | **Contact Details → Edit** |
| Change a contact's phone number | **Contacts → Contact → Edit** |
| Add or manage Tags | **Contacts** |
| Add multiple contacts at once | **Contact Import** |
| Remove a contact from the active contact list | **Archive Contact** |

## Frequently Asked Questions

<Accordion title="Why can't I edit the phone number?">
  A contact's phone number can only be changed from the **Contacts** section. Locate the contact, open their record, and select **Edit**.
</Accordion>

<Accordion title="Can I bulk import contacts?">
  Yes. Captivated's [Contact Import](/features/importing-contacts) allows you to add or update multiple contacts using a CSV file.

  Contact Import is available to Administrators and Users who have been given the appropriate permission.
</Accordion>

<Accordion title="How do I delete a contact?">
  Captivated uses **archiving** rather than permanently deleting contacts. Learn more in [Archiving Contacts](/features/archive-contacts)
</Accordion>
