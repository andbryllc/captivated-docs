## Block a Contact

To block a contact:

1. Open the conversation.
2. Open the contact details using the **information** option.
3. Select **Block**.
4. Confirm the action if prompted.

Once blocked, new messages from that contact will no longer route into Captivated.

<Check>
  Only block a contact when you intentionally want to stop receiving messages from them.
</Check>

## Unblock a Contact

If you need to restore messaging access for a blocked contact:

1. Open the contact's details.
2. Select **Unblock**.

After the contact is unblocked, new incoming messages will route into Captivated as expected.

<Note>
  Unblocking a contact does not restore messages that were sent while the contact was blocked.
</Note>

## Need Help?

If you're unable to block or unblock a contact as expected, contact **Captivated Support** using the in-app **Support** option or text **(317) 316-3600**.
