Before importing, take a few minutes to review and clean your data. A well-organized file helps prevent import errors and ensures information like names, phone numbers, Tags, and Notes are added correctly.

## Before You Import

Your import file should:

- Be saved as a **CSV with UTF-8 encoding**
- Include a header/title for each column
- Have first and last names in separate columns
- Include the appropriate mobile phone number for each contact
- Be reviewed for duplicate, incomplete, or inaccurate information

<Warning>
  Review your file carefully before importing, especially when updating existing contacts. Depending on the options you select during the import, existing Tags, Notes, and other contact information may be updated or replaced.
</Warning>

## Preparing Your CSV

Captivated allows you to map information from your spreadsheet to fields within a contact record.

Available fields include:

- Prefix
- First Name
- Last Name
- Suffix
- Salutation
- Company Name
- Phone Number
- Email
- Tags
- Notes

The following fields are searchable within Captivated: **First Name, Last Name, Company Name, Phone Number, and Tags.**

### Separate First and Last Names

First and last names should be stored in separate columns.

This is especially important when using merge fields such as `{{salutation}}`, which allows Captivated to personalize a message using only the contact's first name.

If your spreadsheet has a single **Full Name** column:

1. Insert an empty column next to the name column.
2. Select the name column.
3. In Excel, select **Data → Text to Columns**.
4. Choose **Delimited**.
5. Select **Space** as the delimiter.
6. Select **Finish**.

<Tip>
  Review the results afterward. Contacts with prefixes, suffixes, middle names, or multi-word last names may need to be corrected manually.
</Tip>

![Split a cell video](https://play.vidyard.com/k2Ku1BKQiNozscSRQc5vd7.jpg)

#### Fix Names in ALL CAPS

If names are formatted in all capital letters, Excel's `PROPER` formula can make them easier to use in personalized messages.

For example:

**MICHAEL SCOTT → Michael Scott**

1. Insert a new column next to the existing name column.
2. Enter the `PROPER` formula referencing the appropriate cell. For example: `=PROPER(A2)`
3. Press **Enter**.
4. Drag the formula down to apply it to the remaining contacts.

This prevents a personalized message such as `Hi {{salutation}}` from displaying as `Hi MICHAEL`.

![Remove capitalization video](https://play.vidyard.com/v7q9cRHEtCWf9T62EGE75p.jpg)

#### Choose a Mobile Number When Multiple Numbers Exist

Your source file may contain several phone-number fields, such as:

- Mobile Phone
- Home Phone
- Business Phone
- Preferred Phone

If needed, you can use an Excel `IF` formula to create a single **Import Phone** column based on the order in which you'd like Excel to look for an available number.

For example:

`=IF(AM2<>"",AM2,IF(AK2<>"",AK2,AH2))`

This tells Excel to use the first available value from the phone-number columns you've specified.

<Warning>
  Review the resulting Import Phone column before uploading your file to make sure the appropriate numbers were selected.
</Warning>

![Locate import phone number video](https://play.vidyard.com/eYr3JvB34K3jYuVJgf4R6W.jpg)

#### Remove Names or Other Text from Phone Numbers

Phone-number fields should contain phone numbers rather than names or other text.

If your source data includes additional information in the same column:

1. Select the affected column.
2. Navigate to **Data → Text to Columns**.
3. Choose **Fixed Width**.
4. Set the break immediately after the phone number.
5. Complete the split and review your results.

## Import Your Contacts

Where you access Contact Import depends on your Captivated permissions.

**Administrators:** Navigate to **Administration → Import Contacts**.

**Users with Contact Import permission:** Navigate to **Contacts** and select the option to import contacts.

![Administration import contacts](https://learn.captivated.works/wp-content/uploads/2019/01/Screenshot-2023-09-25-at-2.41.11-PM.png)

Select your prepared CSV file to begin.

If your organization uses [Contact Ownership](/integrations/contact-ownership), you'll also have the option to configure ownership during the import.

## Map Your Columns

After uploading your CSV, map each column in your spreadsheet to the corresponding Captivated contact field.

For example:

| CSV Column | Captivated Field |
| :-- | :-- |
| First | First Name |
| Last | Last Name |
| Mobile | Phone Number |
| Email Address | Email |
| Customer Type | Tags |
| Account Notes | Notes |

<Warning>
  Carefully review your field mapping before continuing. Data that isn't mapped to a Captivated field will not be imported.
</Warning>

![Column mapping dropdown](https://learn.captivated.works/wp-content/uploads/2019/01/Screen-Shot-2022-08-03-at-2.50.29-PM.png)

## Updating Existing Contacts

During your import, pay close attention to the options for handling contacts that already exist in Captivated.

Depending on the information being imported, you'll have options to **update** or **not import** existing information.

You'll also need to determine how Captivated should handle existing **Tags and Notes**.

![Import mapping options](https://learn.captivated.works/wp-content/uploads/2019/01/Screenshot-2023-09-25-at-2.46.33-PM.png)

### Add vs. Replace

**Add** keeps the contact's existing information and adds the information from your CSV.

**Replace** removes the existing information for that field and replaces it with the information contained in your CSV.

<Warning>
  Use **Replace** carefully. If a contact already has Tags or Notes you want to keep, replacing that information may remove the existing data.
</Warning>

Take a moment to review these selections before starting the import.

## Complete the Import

Once you've:

1. Uploaded your CSV
2. Mapped your columns
3. Reviewed how existing contacts should be handled
4. Reviewed your Tags and Notes settings
5. Configured Contact Ownership, if applicable

select **Import**.

After the import is complete, a confirmation banner will display the number of contacts imported.

## Giving a User Contact Import Permission

Administrators can allow non-Administrator Users to import contacts.

Navigate to:

**Administration → Users → Select User → Edit → Advanced Settings → Contact Import**

Enable Contact Import and save your changes.

The User can then access the import functionality from the **Contacts** section.

## Frequently Asked Questions

<Accordion title="Why am I seeing odd symbols or text after selecting my file?">
  Make sure your spreadsheet is saved as a **CSV with UTF-8 encoding**, rather than an Excel `.xlsx` file.

  In Excel, use **Save As** and select the appropriate CSV UTF-8 file format before trying the import again.
</Accordion>

<Accordion title="Why didn't my contacts import?">
  First, check that:

  - Your CSV has column headers.
  - First Name, Last Name, and Phone Number are mapped correctly.
  - Your phone-number column doesn't contain letters or other invalid information.
  - The fields containing the information you want imported were mapped during the import.
</Accordion>

<Accordion title="What is a Tag?">
  [Tags](/features/tagging-contacts) help organize and group contacts in Captivated. They can also be used to build recipient audiences for [Announcements](/features/announcements).
</Accordion>

<Accordion title="Why don't I see Contact Ownership?">
  [Contact Ownership](/integrations/contact-ownership) is not enabled for every Captivated organization.

  If your organization would like to use Contact Ownership, contact your Captivated Administrator or Captivated Support.
</Accordion>

<Accordion title="Why don't I see the option to import contacts?">
  Contact Import is permission-based.

  If you're not an Administrator and don't see the import option, ask your Captivated Administrator to enable **Contact Import** under your User's Advanced Settings.
</Accordion>

## Need Help?
